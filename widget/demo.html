Kurix Widget — Demo

Esta página carga el widget contra una API local. Ingresá la API key del tenant (la imprime el seeder de desarrollo) y la URL de la API, y recargá el widget.

Embeber en producción (2 líneas)

<script src="https://cdn.kurix.io/widget.js" data-tenant="API_KEY"></script>
